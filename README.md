## Технологический стек

### Frontend
- **React 18** - библиотека для построения пользовательских интерфейсов
- **TypeScript 4.9** - статическая типизация для надежности кода
- **Styled Components 6.0** - CSS-in-JS для стилизации компонентов
- **Create React App 5.0** - инструмент для быстрой настройки проекта

### Управление состоянием
- **Zustand 4.4** - легковесная библиотека для управления состоянием

### Графика
- **HTML5 Canvas API** - для экспорта в PNG
- **CSS Grid** - для отображения пиксельной сетки

### Утилиты
- **UUID** - для генерации уникальных идентификаторов проектов
- **Local Storage API** - для сохранения проектов в браузере

### PWA
- **Service Workers** - для офлайн-работы
- **Web App Manifest** - для установки на устройства

## Типизация TypeScript
- Полная типизация всех компонентов
- Интерфейсы для данных и пропсов
- Строгая типизация событий

## Особенности

### Основные инструменты
- **Кисть** - рисование отдельных пикселей
- **Ластик** - удаление пикселей
- **Заливка** - заливка областей (алгоритм flood fill)
- **Залить весь холст** - заполнение всего холста выбранным цветом

### Настройки холста
- Выбор размера сетки (8×8 до 64×64 пикселей)
- Настройка размера отображения пикселей
- Смена цвета фона

### Работа с цветом
- Палитра предустановленных цветов
- Пользовательский выбор цвета (color picker)
- Просмотр текущего цвета

### Управление проектами
- Сохранение проектов в локальное хранилище
- Загрузка сохраненных проектов
- Управление списком проектов (переименование, удаление)
- Экспорт/импорт проектов в формате JSON
- Экспорт рисунков в PNG


### История действий
- Отмена/возврат действий (undo/redo)
- Автоматическое сохранение истории
- Визуализация истории

## Быстрый старт
### Предварительные требования
- Node.js 16 или выше
- npm или yarn

## Установка и запуск
```bash
# Клонирование репозитория
git clone https://github.com/lina-whm/pixel-art-editor.git
cd pixel-art-editor

# Установка зависимостей
npm install

# Запуск в режиме разработки
npm start

# Приложение будет доступно по адресу: http://localhost:3000

# Сборка для production
npm run build

# Деплой на GitHub Pages
npm run deploy
```
